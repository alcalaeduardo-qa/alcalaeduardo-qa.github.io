Todo el sitio está en español e inglés.

## Diseño

Diseño claro con tarjetas en mosaico y brillos violeta, inspirado en el estilo de la web de Lifemed. Todas las animaciones están hechas desde cero con CSS y JavaScript, sin librerías ni recursos de terceros:

- Pantalla de carga con el logo dibujándose.
- Anillo de vidrio iridiscente detrás del titular.
- Titulares que aparecen letra por letra.
- Texto que se revela palabra por palabra al bajar.
- Carpeta con pestañas que cambian solas.
- Diagrama de flujo con puntos en movimiento.

Si el sistema tiene activado "reducir movimiento", las animaciones se apagan y el contenido se muestra completo.

## Verlo en local

```bash
python -m http.server 8000
```

Después abre `http://localhost:8000`.
