# Eduardo Alcalá García — QA Engineer Portfolio

Portfolio personal desplegado en GitHub Pages.

## 🚀 Deploy en GitHub Pages

1. Crea un repo en GitHub llamado `alcalaeduardo-qa.github.io`
2. Sube todos los archivos de esta carpeta
3. Ve a Settings → Pages → Source: main branch / root
4. Tu portfolio estará en: `https://alcalaeduardo-qa.github.io`

## 📁 Estructura

```
portfolio/
├── index.html          ← Toda la página (HTML + CSS + JS)
├── assets/
│   ├── img/
│   │   ├── profile.png       ← Tu foto
│   │   ├── jira-bugs.png     ← Screenshot Jira
│   │   └── qa-launcher.png   ← Screenshot Launcher
│   └── docs/
│       └── CV_Eduardo_Alcala_QA.pdf
└── README.md
```

## ✏️ Personalización pendiente

1. **Formspree**: En el form action, reemplaza `YOUR_FORM_ID` con tu ID de Formspree
   - Ve a formspree.io → New Form → copia el ID
2. **Dominio personalizado** (opcional): Agrega un archivo `CNAME` con tu dominio

## 🌐 Dominio personalizado (opcional)

Si compras `eduardoalcala.dev`, crea un archivo `CNAME` con:
```
eduardoalcala.dev
```
